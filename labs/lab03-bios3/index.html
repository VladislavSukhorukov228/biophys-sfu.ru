Лабораторная работа №3 · Тестируется

БИОС-3: замкнутая экосистема жизнеобеспечения

Формат: интерактивный симулятор в браузере + настольная версия Статус: тестируется, методические указания готовятся Прототип: эксперименты БИОС-3 Института биофизики (Красноярск)

Цель работы

Изучить принципы работы замкнутых систем жизнеобеспечения на модели, воспроизводящей логику знаменитых красноярских экспериментов БИОС-3: связать фотосинтетическое звено (микроводоросли, высшие растения), газообмен экипажа и круговорот вещества в замкнутом объёме, найти условия устойчивого баланса O₂/CO₂ и продовольствия.

Научная модель

Балансовая модель массо- и газообмена замкнутой экосистемы: продукция кислорода фотосинтезирующим звеном, потребление экипажем, взаимные ограничения площадей посевов, запасов воды и энергии. Игровые решения проверяются расчётом баланса на каждом шаге моделирования.

Запуск работы

Браузерная версия работает на компьютере и смартфоне. Настольная версия для Python (tkinter + matplotlib) — та же модель с расширенными графиками.

Открыть симулятор Настольная версия (.py)

Для настольной версии нужен Python 3 с библиотеками tkinter и matplotlib.
