Лабораторная работа №5 · Готовится к публикации

Эволюция: физика жизни (хищник–жертва)

Формат: интерактивная 3D-симуляция в браузере Статус: тестируется, методические указания готовятся Апробация: школы Красноярского края

Цель работы

Исследовать механизмы естественного отбора и динамику популяций в агентной модели «хищник–жертва»: проверить учебные гипотезы о влиянии температуры, скорости восстановления ресурса и силы мутаций на численность, размер тела и энергетический баланс организмов.

Научная модель

Полная физическая модель: метаболизм по правилу Q₁₀ Вант-Гоффа (Base·m·2^((T−20)/10)), кинетическая стоимость движения k·m·v², передача энергии по трофической цепи ~10 % (правило Линдемана), логистический рост субстрата (Ферхюльст), динамика «хищник–жертва» Лотки–Вольтерры, геном из пяти признаков с гауссовыми мутациями и естественный отбор. Восемь готовых экспериментальных гипотез и экспорт данных в CSV.

Запуск работы

Файл симуляции готовится к размещению — страница уже зарезервирована, кнопка запуска появится после загрузки.

Доступ действует до закрытия вкладки.

Практикум «Экоэнергетика» (.zip) 3D-симулятор скоро появится

Для «Экоэнергетики» нужен Python 3; pygame и openpyxl — по желанию (без них работает расчётный режим с выгрузкой в CSV). Начните с python main.py --selftest.
