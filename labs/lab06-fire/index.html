Лабораторная работа №6 · Настольная (Python)

Огненный фронт: перколяция и лесные пожары

Формат: настольная игра-лаборатория на Python (pygame) Статус: тестируется, методические указания готовятся Модель: клеточный автомат Бака–Ченя–Танга

Цель работы

Экспериментально исследовать перколяционный переход на модели распространения лесного пожара: найти критическую плотность леса (ρкр ≈ 0,59), при которой огонь начинает охватывать весь массив, и изучить влияние ветра, влажности и противопожарных разрывов на границу перехода.

Научная модель

Клеточный автомат Бака–Ченя–Танга (1990) с расширением на ветер, влажность и тип горючего; пожарная опасность по индексу Нестерова. Встроенная «Лаборатория перколяции»: одиночные и серийные эксперименты (до 100 прогонов) с автоматическим экспортом результатов и теоретической сигмоидой в Excel.

Запуск работы

Игра запускается на компьютере: скачайте файл и выполните его в Python.

Доступ действует до закрытия вкладки.

Скачать fire_game.py

Требуется Python 3 и библиотеки pygame и openpyxl: pip install pygame openpyxl, затем python fire_game.py. Windows-версия (.exe) появится после сборки.
